# Marketplace — Telegram Mini App (демо-прототип)

Адаптивный marketplace UI на Next.js 14, React и TypeScript. Визуальная тема — neon, баннеры — универсальный маркетплейс. Название интерфейса: «Marketplace».

## Запуск локально

Требуется Node.js 18.17+ (рекомендуется Node.js 20).

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. В обычном браузере приложение работает как адаптивный сайт. В Telegram Mini App загружается Telegram WebApp SDK, приложение вызывает `ready()` и `expand()`, устанавливает цвета шапки/фона и учитывает безопасные области мобильного экрана.

## Деплой через GitHub и Vercel

1. Создайте репозиторий GitHub и загрузите содержимое этой папки (не ZIP-файл как единственный файл — нужны именно файлы проекта).
2. Откройте https://vercel.com/new и импортируйте репозиторий.
3. Оставьте настройки Next.js по умолчанию и нажмите Deploy.
4. После деплоя скопируйте HTTPS-адрес.
5. В Telegram откройте `@BotFather`, настройте Mini App / Menu Button и укажите HTTPS-адрес как URL приложения.

Для текущего демо переменные окружения не требуются.

## Демо-функции

- Главная лента с автоматически меняющимися баннерами и ручным переключением.
- Поиск по названию, описанию и продавцу; фильтр по категории/подкатегории.
- Просмотр карточки объявления, избранное и форма жалобы.
- Создание тестового объявления с имитацией загрузки фото.
- Профиль, каталог магазинов и демо-витрина, FAQ.
- Админ-панель с демонстрационными разделами пользователей, жалоб, статистики, ролей и рекламы.
- Демо-центр: тестовые роли, очередь жалоб, обязательный комментарий модератора, подтверждение владельцем, отзывы и сброс данных.
- Демо-данные сохраняются в `localStorage` текущего браузера и устройства. Они не синхронизируются между пользователями и не являются настоящей базой данных.

## Рекомендуемые сценарии проверки

1. **Поиск и избранное:** откройте главную, введите «наушники», откройте карточку и добавьте её в избранное. Перейдите в «Избранное».
2. **Создание объявления:** откройте «Личный кабинет» → «Добавить», заполните название, цену и описание, нажмите «Добавить фото», затем «Опубликовать». Проверьте карточку в своих объявлениях.
3. **Жалоба и модерация:** откройте объявление → «Пожаловаться», заполните описание и отправьте. Откройте «Демо-центр», добавьте комментарий модератора и нажмите «На одобрение».
4. **Одобрение владельцем:** в демо-центре выберите роль «Владелец» и подтвердите решение кнопкой «Одобрить» у жалобы с комментарием.
5. **Отзывы:** в демо-центре выберите рейтинг, напишите отзыв и добавьте его.
6. **Магазины и FAQ:** откройте разделы через боковое меню или мобильную нижнюю навигацию, затем откройте витрину магазина.
7. **Сохранение:** обновите страницу — демо-объявления, избранное, жалобы, отзывы и выбранная роль должны остаться в этом браузере.
8. **Сброс:** внизу демо-центра нажмите «Сбросить демо-данные» и подтвердите действие.
9. **Telegram:** сначала проверьте сайт локально в браузере, затем после HTTPS-деплоя откройте URL из Telegram Mini App на телефоне.

## Важно: границы демо-режима

Этот проект позволяет проверять клиентский интерфейс и базовые сценарии, но это ещё не production-маркетплейс. Роли и решения модерации имитируются на клиенте; локальные данные можно изменить в браузере. Загрузка фотографий имитируется. Уведомления и переход к продавцу показывают демо-сообщения. До публичного запуска нужно добавить серверную авторизацию Telegram, базу данных, объектное хранилище изображений, серверные проверки ролей, API для объявлений/жалоб/отзывов и реальные уведомления.

Никогда не доверяйте `initDataUnsafe` как доказательству личности и не помещайте токен бота или секретные ключи в клиентский код либо переменные `NEXT_PUBLIC_*`. Сервер должен проверять исходный `Telegram.WebApp.initData`.

## Быстрая проверка перед публикацией

- [ ] `npm install` завершается без ошибок.
- [ ] `npm run dev` открывает приложение на `http://localhost:3000`.
- [ ] Проверены размеры мобильного экрана и нижняя навигация.
- [ ] В демо-центре можно изменить роль, отправить жалобу, оставить комментарий и одобрить решение владельцем.
- [ ] Созданный отзыв и избранное сохраняются после перезагрузки.
- [ ] Кнопка сброса возвращает исходный набор демо-данных.
- [ ] `npm run build` завершается успешно до деплоя.

## Что означает «полноценный демо-режим» в этой сборке

Это интерактивный клиентский прототип: доступные формы и сценарии предназначены для ручного тестирования, а данные сохраняются в `localStorage` одного браузера. Административные цифры и часть административных экранов являются демонстрационными макетами. Нельзя использовать демо-выбор роли как настоящую авторизацию. До публичного запуска необходимо вынести данные в БД и реализовать серверные API с проверкой `Telegram.WebApp.initData`, прав доступа и действий модерации.
